## 当前行为

任务卡的 waiting_approvals 列表现在逐条显示管理员审批组件。输入本次页面使用的管理员凭据后读取详情，完整展示 binding_json，包括实际参数、目标、节点/工作流/版本上下文，以及 action_digest、任务、操作、有效期、状态。详情为可选择的全文，不以截断摘要替代。

批准/拒绝前会重新读取同一个审批 ID，检查仍为 pending、摘要未变化且没有过期。单条请求期间禁止重复点击，各审批 ID 独立处理。决定受理后重新读取审批与原任务，每 5 秒更新；202 不显示为任务成功。拒绝沿用服务端取消原任务的语义。

凭据只在组件/会话内存中使用，可手工清除，页面销毁后不持有；没有写入 AsyncStorage、离线队列、通知或普通 API 客户端全局默认头。Task 查询的显式 token 参数仅供该审批会话更新原任务状态。错误消息按 HTTP 状态映射，不显示服务端错误正文或输入凭据。

网络失败保留本页已读取的详情，禁用审批直至在线刷新；不缓存离线决定，不自动重发 POST。请求可能已生效但回包丢失时，先按原 ID 查询最新状态。凭据、在线状态、任务或组件切换后，旧请求的响应不能重新启用按钮。
