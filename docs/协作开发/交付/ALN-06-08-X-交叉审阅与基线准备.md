|---|---|
| 资产 API | 测试显式导入掩盖生产404；server注册资产域，统一鉴权限制POST为admin。全新子进程HTTP覆盖读取、operator拒绝与admin登记 |

| 回收保护 | rollback_ref未计引用，已发布/运行冻结版本也可能被回收；现同时保护回滚引用、release/runtime/task/run已有asset_refs |
| 并发计量 | App共享MeteredModel，last_usage被其他任务覆盖；现同一适配器调用与采集串行，每线程保存调用证据供任务预算结算 |
| 用量与价格 | 负数/小数/bool/非有限token被截断或计费；非法价格和溢出会污染成本。现拒绝非法实测，回退明确estimate；非法/缺失价格与金额溢出保留unknown |
| 模型路由 | 显式/默认可选择available=False；视觉需求最终回退文本模型；最高分无法解析就跳过其他可用模型。现复核实际适配器能力，遍历可用候选，无兼容回退则拒绝 |
| 未知价格 | 路由把unknown默认0视为便宜。现unknown不获得免费成本优势，成本优先仅比较已知价格，rank输出price=null及pricing_status |
| 敏感错误 | HTTP正文和运输异常字符串可能回显密钥/用户输入；持久化错误只保留HTTP状态和异常类别 |
