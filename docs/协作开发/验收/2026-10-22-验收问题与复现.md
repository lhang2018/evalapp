### CXR-01 资产作用域不可用时静默降级

位置：`evoagent/evolution/asset_impact.py:7-8`。存储缺失时返回 `asset_scope_status="unavailable"` 且 `asset_scope_errors=[]`；`evoagent/evolution/regression_gate.py:82` 只收集 errors 作为阻止原因。

复现：

```python
from evoagent.evolution.asset_impact import asset_impact
print(asset_impact(None, "expert/general", ["general"]))
# {'asset_refs': [], 'asset_scope_status': 'unavailable', 'asset_scope_errors': []}
```

影响：若 `self.store` 装配缺失，资产相关必跑套件与领域不会进入回归范围，门禁仍可能通过。正常 App 装配会传入真实 store，故列为降级路径风险。

### CXR-02 空评测明细未被门禁拒绝

位置：`evoagent/evolution/evaluator.py:242`。只有 `case_results` 非空时才校验“明细/样本数量一致”。

复现：

```python
from evoagent.evolution.evaluator import EvalReport, ReleaseGate, GateThresholds
b = EvalReport("d", "1", True, success_rate=1.0, case_count=1, pass_count=1,
               safety_passed=True, safety_cases=1)
b.metadata["dataset_digest"] = "x"
c = EvalReport("d", "1", False, success_rate=1.0, case_count=1, pass_count=1,
               safety_passed=True, safety_cases=1)
c.metadata["dataset_digest"] = "x"
print(ReleaseGate().judge(b, c, thresholds=GateThresholds(min_cases=1)))
# passed=True, reasons=[]
```

影响：`case_count>0` 但明细为空、成功率自填的报告可过门禁。当前评测器生成路径必然写入明细，属于防御性缺口。

### CXR-03 夹具证据缺少 cost_known 时按“有 cost 即已知”处理

位置：`evoagent/evolution/evaluator.py:162`：`evidence.get("cost_known", "cost" in evidence)`。

复现：

```python
from evoagent.evolution.evaluator import Evaluator, EvalCase, EvalDataset
class R:
    def run_case(self, case):
        return True, 0.1, {"cost": 0.2}
case = EvalCase("c1", "goal", failure_fixture={"boom": 1},
                version_manifest={"asset_refs": []})
report = Evaluator(R()).run(EvalDataset("d", cases=[case]), baseline=False)
# cost_known=True, unverified_fixtures=1, cost=0.2
```

影响：自定义 `fixture_runner` 只回 `cost` 而未声明来源时，成本被视为已知。该用例同时因夹具未复现被 `unverified_fixtures` 拦截，正常门禁仍会失败；属于证据语义收紧项。
