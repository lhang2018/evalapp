## 发现与修复

| 编号 | 优先级 | 原行为及复现 | 修复结果 |
|---|---|---|---|
| CR11-01 | P1 | 带真实制品字段的目标仍能 `verify()` → `activate()`，不下载、不验签、不装载也可记 active | 真实制品或已配置真实更新端口时拒绝旧入口；激活必须有匹配的真实制品 |
| CR11-02 | P1 | prepare 后改文件、撤销权限或使密钥过期，activate 仍调用装载器；新真机装载器也不核对它读到的字节 | 激活前重验版本、契约、权限、实际字节及当前密钥有效期；装载器再核对自己读到的摘要 |
| CR11-03 | P1 | 回滚只切状态标记，未恢复实际能力包；装载器失败也能报告回滚成功 | 保存原制品路径，回滚重新校验并实际装载健康包，成功后才切槽和报告 |
| CR11-04 | P1 | 连续激活两个未健康确认版本会把健康版本替换成未验证的前一版本 | 真实制品只在 `healthCheck(true)` 后更新 last-known-good；三版本回退验证通过 |
| CR11-05 | P1 | 未知总长下载只检查 total，不检查累计字节；缓存正式文件可跳过 maxBytes | 写入前、暂存恢复和缓存复用均执行上限，非法数值/分块大小拒绝 |
| CR11-06 | P2 | release_id 可含 `../`；短版本 `1` 对最低 `1.1.0` 比较误放行 | ID 限定为安全单段；版本补零比较，非法版本拒绝。新版原生桥已有私有目录边界，本修复同时保护可注入内核 |
| CR11-07 | P1 | 51 条未确认回执只保留最后 50 条；4 个并发健康检查只保留 1 条回执 | 不静默截断待确认回执；健康检查与其他状态变更共用串行队列 |
| CR11-08 | P1 | App 无条件装入开发公钥，release 构建也信任本地开发签名 | 开发公钥仅在开发构建加载；生产无配置公钥时拒绝更新 |
| CR16-01 | P1 | dict/EvidenceEvent 会校验，RunEvent 转换不校验，无来源 untrusted 事件可进入导出和决策链 | RunEvent 转换执行同一校验 |
| CR16-02 | P2 | RunEvent 默认 fault_level=none 阻断 error 的故障推断 | 默认 none 按事件类型/严重度推断，error 映射 degraded |
| CR16-03 | P1 | 轮换延长旧凭证已有过期时间；新凭证非法时旧凭证先被退役；client_trust 公钥无法轮换 | 先校验注册再退役，宽限期不超过原截止时间；支持公钥轮换且无需私钥 |
| CR16-04 | P1 | ring 已撤销 token 能回退静态配置继续认证；同一 secret 重复登记可以留下有效副本 | 已归 ring 管理的失效 token 不再走静态回退；拒绝复用同一秘密，其他未纳入 ring 的静态 token 仍兼容 |
| CR16-05 | P1 | task/run 过滤只作用于事件，其他任务审批记录仍进入链并连成 approved_by | 显式冲突的任务/运行记录排除；无作用域的发布/评测记录只沿选中引用链纳入 |
| CR16-06 | P2 | 同一事件集合不同输入顺序生成不同 digest；未传 run_id 时遗漏缺失因果引用 | 稳定排序节点/边/缺失引用，所有入口报告缺失因果事件 |
