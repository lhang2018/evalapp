## 三、语义审查

1. **四阶段分离**：candidate → pre_release → release → observation 各自
   独立表述，scope 显式标注（candidate-only / benchmark-only /
   release-monitored），每阶段一句话摘要。
2. **不可夸大**：基准 improved 强制限定"基准范围，不等于线上收益"；
   无监测 → 不能声称线上；已发布 → "已发布不等于线上有效"。
3. **退化透明**：基准退化 / 发布后回滚 / 十维向量某维度 degraded
   都进 degradations，禁止正向表述。
4. **证据绑定**：每条 claims 携带 basis（candidate/evaluation/benchmark/
   release/monitor）与 evidence_refs（报告 id / 监测 id）——无证据的
   表述只能进 cannot_claim。
