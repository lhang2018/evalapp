# ALN-14-A：机会排序、无进展停止与归因规则（规则与夹具先行）

## 目标

把机会排序、收益/证据/机会成本、无进展定义、深度/数量/重复/环限制写成可配置、版本化的规则；确保持续推进与复盘不绕过审批和预算。交付顺序：规则与不变量表 → 可复现实验夹具 → 实现。

## 验收

- 无进展阈值（按证据、时间、重复失败可配置）触发停止并可复现。
- 递归/重复失败不无限派生子目标；深度/数量/环限制有版本化配置且可审计。
- 授权、期限、预算任一失效即停止新动作。
- 预期与真实收益可归因；unknown 证据不计改善。
