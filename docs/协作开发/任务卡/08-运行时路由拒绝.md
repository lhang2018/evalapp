# ALN-08-R：运行时遵守模型路由拒绝

负责人 codex-runtime。用户明确指出 runtime 共享文件存在拒绝旁路；本卡修复需独立 runtime reviewer，不由作者自批。

## 目标

ModelRouter已拒绝的模型不能由RuntimeController直接回退执行；拒绝和异常不能伪装成source=router的成功选择。

## 写入边界

- core/controller.py::_route_model 最小补丁；复用现有execute失败收尾。
- tests/test_runtime_router_rejection.py 的真实App/持久化/事件/评测一致性回归。
- ALN-08历史验证说明、交付、认领记录与候选验证证据；不纳入其他人在途通知/ALN-09测试。

## 验收

- 不可用默认模型、路由ValueError/其他异常不执行react.model。
- 规划成功后执行阶段拒绝，清除旧选中模型，任务持久化FAILED。
- 拒绝记录router_rejected，其他路由异常记录router_error；事件绑定task/run。
- 路由器自己批准的可用fallback仍正常执行；unknown override告警后仍经过普通路由验证。
- 同一不可用模型配置下评测和运行时均拒绝；原首轮证据明确标历史。
