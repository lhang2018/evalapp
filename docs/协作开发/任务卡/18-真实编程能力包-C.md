# ALN-18-C：原子多文件补丁与 dry-run 预览

建议角色：runtime。承接 ALN-18-A/B：单文件改写已有语法门禁与摘要保护，但跨文件改动仍是「改一个算一个」——第二处失败会留下半套改动。

## 目标

交付 `coding_patch`：

- 一次提交多条 `{path, old_text, new_text, expected_sha256?}` 编辑，最多 50 条、每个文件最多一条。
- **预检阶段**完成全部校验：路径边界、文件存在、旧文本唯一命中、摘要匹配、改写后语法合法、内容确有变化；任一失败则**不写盘**。
- **提交阶段**写盘后逐文件重读比对；任一不一致则回滚所有已写文件；回滚失败必须显式 `side_effect_uncertain`，不得报告成功。
- `dry_run=true` 只返回统一 diff、前后摘要与预计行号，不写盘。
- 证据逐文件给出 `file`、行号、完整 `sha256_before/after`，并汇总 `applied`/`rolled_back`。

## 写入边界

可独占修改：

- `evoagent/tools/coding.py`
- `tests/test_coding_tools.py`
- `docs/协作开发/交付/ALN-18-C-*.md`

不得触碰：注册表、`contract.py`、`app.py`、专家注册表及执行路径共享文件。本卡不接线，不实现注册表级卸载。

## 验收

- 两文件补丁成功：全部写盘、逐文件证据完整、能作为下一次 `expected_sha256` 输入。
- dry-run：返回 diff 与摘要，文件内容与 mtime 语义不变（至少内容不变）。
- 原子性：第二条编辑旧文本不存在 / 语法不合法 / 摘要过期 / 重复路径 → 第一条也不写盘，文件保持原状。
- 相同内容（no-op）明确拒绝，不产生空写。
- 写后校验失败路径必须回滚并如实报告；不能把部分成功报成成功。
- 能力包版本升到 `1.2.0`，`rollback_version=1.1.0`，工具 ID 七个。
- 既有 17 项测试不回归；新增负向专测覆盖上述拒绝路径。
