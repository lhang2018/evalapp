## 验收

零入口域获得可达入口，装配缺口逐项闭合，可达性可机器校验；开发完成不等于发布批准

- deployment / recovery / observability / knowledge 四个零入口域各获得至少一个 CLI 入口，且从 CLI 走通**一条真实路径**（真实落盘、真实恢复，非 mock）
- app.py 装配 ProactiveAssistService；IdentityRegistry 注入 ReleaseDelivery 并在端到端回执路径上生效
- 新增可达性审计：列出每个已交付关键能力的入口，审计结果在装配完成后**零悬空**，且缺入口时必须报错而非静默通过
- 记录正向、失败与恢复/拒绝路径；Mock/夹具明确标注，不能冒充真机或生产实测
- 绑定精确源码commit、命令、结果、日志及必要环境；无证据保持未测试
- 出口证据对应 UX-01（自然语言任务输入建立正确任务类型）、UX-10 / UX-F03-04（重启后状态真实、外部副作用不被盲目重放）
