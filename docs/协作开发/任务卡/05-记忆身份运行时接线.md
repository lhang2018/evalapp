# ALN-05-I：记忆身份与 ContextManifest 运行时接线

2026-10-23由codex-runtime认领，排队；消费已交付05-M，不重做记忆库。原作者与审阅记录保留在原卡。

## 目标

把服务端确认的 user/project/session/task/expert 身份及必要的跨域 grant 贯穿 Task、持久化、Controller 读写与 ContextManifest。当前 controller 仅传专家 scope_key；不能把调用者随意填写的身份当作跨域授权。

## 写入边界

- 可新增身份解析/绑定域模块、身份接线与重启回归测试。
- 共享接线：`evoagent/core/task.py`、`evoagent/core/controller.py`、`evoagent/core/persistence.py`、`evoagent/core/schema/migrations.py`、`evoagent/app.py`，由当前单会话串行修改。
- 消费 `evoagent/memory/` 已有 identity/grant/manifest 接口；不覆盖05-M实现，不顺带做端侧记忆缓存或全套隐私删除。

## 验收

- 主执行路径确实向读侧和写侧传入同一权威身份，专家域隔离仍有效。
- 两个用户/项目/会话使用相同查询时不串读；伪造身份和越权 grant 被拒绝。
- 恢复后保留原身份，不因省略字段回退到宽泛读取；旧任务兼容规则明确且有回归。
- Manifest 可追到本次实际选中的记忆、压缩引用和来源；敏感正文不混入清单。
- API鉴权主体与用户/项目身份的绑定规则先写清楚，不能仅增加几个可选字段就宣称多用户隔离完成。

## 交付

身份绑定契约、兼容/迁移说明、主链正反例与精确提交日志。独立审阅后仅关闭接线范围；05-M原审阅、端侧缓存与隐私验收继续单独跟踪。
