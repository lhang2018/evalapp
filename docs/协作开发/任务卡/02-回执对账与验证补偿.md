# ALN-02-A：回执对账、产物恢复与验证补偿

负责人codex-runtime；接续ALN-01统一网关。

## 目标

调用前绑定不可变参数和版本，未知结果必须独立对账；恢复真实产物；DAG保留原ToolResult；补偿使用原动作证据并验证外部状态恢复。

## 写入边界

core/side_effects.py、persistence.py的执行读写与状态CAS、schema/authorizations.py；tools/registry.py；workflows/models.py、engine.py、compensation.py及示例定义；API、测试和交付记录。

## 验收

进程在外部调用前/后退出均留下submitted及原参数；未知结果不重放；真实HTTP回执核验后原子恢复产物与状态；核验失败不放行；活跃超时线程不能当已取消；已确认未执行才允许新尝试；补偿带原路径/旧内容且经只读工具独立验证，验证失败不标compensated；补偿仍受授权、审批、预算和账本约束，等待后可续跑。

## 交付

通用对账适配契约、本地HTTP与真实文件恢复证据、兼容规则和专项/干净全量日志；代码进入review，生产供应商适配仍需要相应部署环境验收。
