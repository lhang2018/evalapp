# ALN-17-A：备份/恢复闭环加固与迁移回退契约

建议角色：integration。ALN-03/06/16 未关闭的「版本组合恢复」部分不在本卡；本卡只消费已提交的 `evoagent/core/backup.py`、`evoagent/core/schema/migrations.py` 与 ALN-04-R 运行恢复接口，先补数据面最小闭环。

## 目标

现状：`evoagent/core/backup.py` 已有三库打包、manifest 校验和、SQLite `integrity_check`、恢复前安全备份；`schema/migrations.py` 已有版本化迁移台账（`SCHEMA_VERSION = 3`）。缺口：manifest 不含 schema 版本，跨版本恢复不会拒绝或升级；恢复不核对行数快照；迁移失败无回退演练；空机器恢复未覆盖制品引用；恢复耗时/数据损失未测量。本卡先交数据面闭环与可演练契约，不宣称版本资产组合恢复完成。

## 写入边界

可独占新增：`tests/test_backup_recovery.py`、`tests/test_migration_rollback.py`、`tools/measure_backup_recovery.py`、本卡交付文档。

可在本卡内小改：`evoagent/core/backup.py`、`evoagent/core/schema/migrations.py`（只加 manifest `schema_version` 与兼容判定、迁移回退入口，不改既有备份格式语义；旧格式按明确规则拒绝或迁移）。

不得触碰：`evoagent/release/*`（ALN-03/06 在途）、`evoagent/core/events.py` 等 ALN-16 在途共享文件；部署文档/脚本另卡。

## 验收

- manifest 记录 `schema_version`；恢复时当前版本低于备份版本即拒绝并给出可操作原因，高于备份版本按迁移路径升级或明确拒绝。
- 损坏/篡改/缺表的备份拒绝恢复，且当前数据不变（安全备份与原子替换可验证）。
- 迁移失败可回退到迁移前状态；回退后任务/运行历史可读。
- 恢复不执行历史副作用，仅恢复状态；以账本/事件计数与任务状态一致性验证。
- 行数快照与恢复后计数核对，不符即报错。
- 以脚本实测并记录恢复时间与数据损失范围（RTO/RPO），作为 ALN-17 整包证据的一部分。

## 交付

`backup.py`/`migrations.py` 补丁、夹具、测量脚本、命令与日志，使用[统一交付模板](../交付模板.md)。空机器部署文档、制品/版本组合恢复、Mini PC/Linux 常驻部署另卡；本卡不宣布 ALN-17 整包完成。
