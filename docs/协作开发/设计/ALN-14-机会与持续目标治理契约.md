# ALN-14-A：机会、进展与递归治理 v1

消费既有GoalStore和15-R真实预算入口；不新增授权、Goal状态或费用权威。候选、预期效用、已观察进展和发布收益分别记录。

| 规则 | v1不变量 |
|---|---|
| 机会发现 | 只能引用已有Goal或真实终态Task；重复发现幂等。注册仅产生proposed Goal，不授权、不执行 |
| 价值排序 | 预期收益×证据置信×剩余时效−费用权重×预计USD成本−风险惩罚−机会成本；所有数值有限非负，未知成本/证据不可排名，过期排除，同分按候选ID稳定排序 |
| 规则版本 | ref不可变；严格校验阈值和验收条件。manual-review/v1为保守一次尝试后复盘，不能把旧占位引用解释成无限运行 |
| 改善 | 只认预先登记的客观验收条件首次通过；结果非空、模型自评、重复通过、未知计费/副作用或不确定检查不算新改善 |
| 停止 | 无改善次数、连续失败、重复状态、无改善时间、总尝试次数任一达到阈值即停止；授权/期限使用13，费用占用使用15-R；停止原因附Task及policy引用 |
| 持续推进 | 显式调用、有步数上限；每步仍由Controller.submit_task创建并执行advance Task。根目标族一次仅允许一个未结束的advance，等待审批/暂停/崩溃的Task不重新提交 |
| 递归 | 在GoalStore同一创建事务检查祖先政策的相对深度、直接子数、全后代数量、规范化目标重复/祖先循环；包括已取消子目标，不能删除计数绕过 |
| 父链 | 父目标停止后，子Goal/普通execute/新子目标不能绕开；原普通人工Goal在未启用治理时保持兼容 |
| 复盘 | 终态Task观察只从DB读取，幂等持久记录。达成全部登记条件进入review，不自动completed。停止后显式人工复盘可开启新轮，保留已达成条件和全部历史、预算与递归计数 |

登记客观条件由可信管理入口执行，使用已有规则验收器支持的result_contains/result_matches/data_equals/tool_goal_reached；不接受可执行custom函数。登记条件是长期进展的操作性定义，不能将其冒充真实生产收益。未配置该映射时没有自动改善证据，只允许保守尝试和停止。

Goal/action检查在实际模型/工具边界读取当前政策与真实Task历史；即使复盘状态写入尚未发生，达到阈值也拒绝新动作。持续Task最终落账后持久观察并暂停/转review；旧run不重发，跨重启重新读取同一Task与规则。

推进命令绑定max_steps并持久保存结果；同键变更步数拒绝。中断或并发请求只恢复已有Task引用，不重新领取执行，可通过原Task恢复入口或新显式命令继续。客观观察一经保存不可被修改Task结果覆盖。未知费用只有对应持久预留均已闭合且存在足额真实reconcile回执后，才允许人工复盘开启新轮；旧观察仍不计改善。人工复盘不补满原聚合预算，也不重置递归计数。

API写操作要求传输层admin；body不能冒充actor。候选outcome将预期效用与已登记Goal/Task、客观条件及预留实际结算金额分别关联；production_benefit_verified始终为false，不能以模拟器/字符串条件通过宣称生产收益。

本轮不提供无人值守定时守护、设备优先级调度、外部供应商评测或真实候选收益证明。生产候选对照仍由09/10验收，治理不能自行替其批准。
