# EvoAgent 全量详细设计正式版｜总目录与追踪矩阵

**正式设计基线 1.0｜2026-10-20**

本包包含 **89 个稳定主题 ID**，另有 7 个 Android 子系统、8 个逻辑服务、4 个受保护控制器和 14 项 ADR。此前台账将数量写成 80，本次按实际主题重新核对为 89。

## 阅读顺序
总体架构/PRD → 任务执行内核 → 记忆上下文 → 专家能力与工作流 → 观测诊断评测与进化 → 自主目标与资源治理 → 产品部署/端侧 → 端云同步发布 → 安全工程化 → 数据契约与验收。

## P｜产品与部署
- **P-01｜产品定位与价值主张**：个人通用智能体；真实任务完成、可靠复用和可验证改进。
- **P-02｜全量 PRD 与产品边界**：用户场景、功能需求、非目标、权限、任务生命周期和验收口径。
- **P-03｜Android 手机优先战略**：Android 手机第一正式终端，承载交互、审批、设备能力和运行证据。
- **P-04｜Windows 桌面端扩展路线**：后续增强开发、长任务和桌面工具能力，不作为 Android 首发依赖。
- **P-05｜Mini PC/Linux 个人宿主**：个人电脑或微型 Linux 主机提供常驻服务、文件处理和本地工具。
- **P-06｜多端交互与运行宿主解耦**：Android、未来桌面端、CLI/API 与执行宿主分离。
- **P-07｜本地优先与可选远程服务**：断网保留本地任务状态、事件、可用能力和导出。
- **P-08｜DeepSeek Harness 适配策略**：Harness 作为可替换 Agent Runtime，而非产品架构本身。

## R｜任务执行内核
- **R-01｜统一任务入口与 Task of Record**：统一接收目标、约束、预算、授权和验收条件。
- **R-02｜意图理解与多层路由**：识别领域、复杂度、风险、工具需求和不确定性。
- **R-03｜路由质量评测与纠错**：评估专家选择、工作流匹配、执行模式和模型选择。
- **R-04｜Planner 与计划修订**：目标拆解、依赖、验收和恢复策略。
- **R-05｜ReAct 执行循环**：观察、动作提议、授权检查、执行、再观察和停止。
- **R-06｜DAG/工作流运行时**：节点依赖、条件、并发、重试、审批、检查点和补偿。
- **R-07｜固定流程、混合 Agent 与动态规划选择**：决定采用稳定 DAG、局部 Agent 节点或动态规划。
- **R-08｜工具注册表与能力契约**：工具 Schema、权限、风险、超时、幂等、成本和健康检查。
- **R-09｜Action Guard 与动作授权**：执行前检查工具权限、目标范围、风险、预算和用户授权。
- **R-10｜取消、暂停、等待与人工接管**：任务控制、审批等待、补充信息和人工接管。
- **R-11｜检查点与恢复管理**：保存 DAG 节点状态、恢复游标和必要输入输出引用。
- **R-12｜外部副作用账本**：跟踪外部操作意图、提交、确认、失败和对账状态。

## M｜记忆上下文
- **M-01｜用户长期记忆**：稳定偏好、长期约束和可复用授权偏好。
- **M-02｜项目记忆**：项目决策、当前状态、技术约束、里程碑和未决事项。
- **M-03｜领域记忆命名空间**：旅游、编程、漫剧、手机操作等专家的领域经验隔离。
- **M-04｜会话上下文管理**：当前对话近期信息、指代、未解决问题和交互状态。
- **M-05｜任务工作记忆**：当前任务计划、观察、证据、中间结果和未决步骤。
- **M-06｜上下文压缩与预算管理**：窗口限制下保留目标、约束、决策、验收、未决项和来源。
- **M-07｜上下文来源追踪与可信度**：追踪来源、摘要引用、时间、版本和可信状态。
- **M-08｜记忆冲突与事实更新**：处理新旧偏好、项目决策、外部事实和推断冲突。
- **M-09｜记忆写入门禁**：决定运行结果是否能转为长期记忆或能力资产。
- **M-10｜记忆保留、删除与隐私**：过期、删除、导出、敏感内容和派生摘要治理。

## C｜专家能力与工作流
- **C-01｜专家注册表**：领域、能力、工具、工作流、记忆、模型和评测声明。
- **C-02｜受保护共享通用内核**：共享任务身份、状态、权限、预算、事件、恢复和发布规则。
- **C-03｜领域专家隔离与独立进化**：专家独立提示词、知识、工具、工作流、记忆和评测。
- **C-04｜Tool、Skill、Workflow、Expert 边界**：明确原子工具、操作知识、可执行流程和领域专家的职责。
- **C-05｜Capability Pack 能力包**：按业务目标打包工具、技能、工作流、评测和依赖。
- **C-06｜执行轨迹到工作流编译**：从成功/失败轨迹生成候选 DAG 和恢复分支。
- **C-07｜工作流适用性匹配**：目标、输入 Schema、工具、模型、预算、权限和兼容性匹配。
- **C-08｜能力资产生命周期**：Draft、Candidate、Validating、Approved、Active、Degraded、Retired。
- **C-09｜能力依赖图与影响分析**：追踪资产依赖和受影响回归范围。
- **C-10｜能力去重、别名与合并**：识别重复技能、工具包装和相似工作流。
- **C-11｜经验来源与能力晋升证据**：把运行经验转为策略、技能、工作流或工具改进。
- **C-12｜编程专家的 AST/LSP/类型检查能力**：语法树、符号索引、类型检查、测试和静态分析。
- **C-13｜AI 漫剧制作能力包**：脚本、分镜、素材、角色一致性、生成、配音、FFmpeg 合成和验收。
- **C-14｜Android 受控手机操作能力包**：受控观察、动作、权限检查和真实状态验证。

## E｜观测诊断评测与进化
- **E-01｜运行事件与 Trace**：记录 task/run/node/tool/model/asset 版本、成本、时延和结果。
- **E-02｜统一故障分类与证据等级**：区分规划、模型、工具、供应商、网络、权限、预算和验收故障。
- **E-03｜诊断与执行解耦**：分析根因并提出改进，不在生产路径直接修改。
- **E-04｜工具健康与 Agent 能力分离**：分开评估工具可用性和智能体任务能力。
- **E-05｜QEEG 质量工程与评测治理**：独立验证任务质量、成功率、成本、时延、安全和兼容。
- **E-06｜评测集版本、覆盖与防泄漏**：管理测试样本、标签、来源、难度、覆盖和保密。
- **E-07｜进化候选生成**：从失败、成本异常、质量退化和能力缺口提出改进。
- **E-08｜隔离实验环境**：隔离候选代码、配置、数据、凭证、网络和资源。
- **E-09｜发布晋级门禁**：决定候选是否可发布、灰度、晋级或拒绝。
- **E-10｜稳定轨道与候选轨道隔离**：生产任务绑定稳定资产，实验在候选轨道执行。
- **E-11｜进化收益与退化评估**：测量改进对质量、效率、恢复和稳定性的实际影响。
- **E-12｜失败案例转回归资产**：把真实失败转成可复现测试。
- **E-13｜独立进化控制器**：管理诊断队列、候选计划、实验预算、并发和停止条件。

## G｜自主目标与资源治理
- **G-01｜长期目标注册表**：保存用户目标、维护目标、派生子目标和主动机会。
- **G-02｜主动机会发现**：从运行证据、质量退化和用户目标发现机会。
- **G-03｜目标价值评估与排序**：比较收益、证据、成本、风险、时效和机会成本。
- **G-04｜自主等级与授权矩阵**：建议、准备、沙箱、授权内执行和长期推进的权限分层。
- **G-05｜Goal 状态机**：管理目标提出、运行、等待、暂停、阻塞、完成和过期。
- **G-06｜无进展检测与停止控制器**：识别循环、重复失败、收益递减、预算耗尽和目标失效。
- **G-07｜递归子目标治理**：管理拆分深度、数量、循环依赖和重复子目标。
- **G-08｜前台/后台资源调度**：协调交互任务、长任务、同步、评测和进化实验。
- **G-09｜预算账本与费用控制**：管理模型 token、外部 API、生成服务、CPU/磁盘和并发预算。
- **G-10｜主动任务结果归因**：比较预期收益与实际收益，决定继续、暂停或终止。

## O｜端云协同与可靠性
- **O-01｜本地事件持久化与容量治理**：关键事件、版本清单和同步状态本地可靠保存。
- **O-02｜可靠同步与幂等回执**：断点续传、稳定事件 ID、批次 ID、部分成功回执和退避。
- **O-03｜离线诊断包导出**：按任务、时间、能力和失败状态导出结构化证据。
- **O-04｜诊断包受控导入**：校验外部包、隔离数据并进入诊断流程。
- **O-05｜Runtime Manifest 运行版本清单**：记录每次任务实际使用的组件版本组合。
- **O-06｜端云协同进化闭环**：证据上行、诊断、候选评测、发布下行和线上反馈。
- **O-07｜版本分发、激活与回滚**：分发策略、工作流、模型档案、能力包和客户端制品。
- **O-08｜离线降级与恢复**：服务端、模型、网络或同步不可用时保留允许的本地能力。
- **O-09｜附件与大型资产存储**：管理图片、音频、视频、代码产物和诊断附件。
- **O-10｜多设备状态一致性**：维护设备版本、目标发布、激活状态和应用回执。

## S｜安全与工程化
- **S-01｜安全策略与最小权限**：统一工具权限、数据范围、风险等级、审批和拒绝规则。
- **S-02｜隐私与敏感数据治理**：最小化采集、脱敏、访问控制、保留和删除。
- **S-03｜模型输出与外部内容不可信边界**：防止提示注入、恶意工具参数和导入指令。
- **S-04｜本地沙箱与执行隔离**：隔离候选代码、文件系统、进程、网络和资源。
- **S-05｜审计日志与决策可解释性**：记录授权、执行、诊断、评测、发布、回滚和审批。
- **S-06｜ADR 架构决策治理**：记录决策、替代方案、原因、影响、状态和取代关系。
- **S-07｜自动化测试与端到端验收**：单元、集成、回归、失败注入、兼容和端到端流程。
- **S-08｜模块化单体与技术基线**：定义首期语言、存储、协议、目录、依赖和拆分条件。
- **S-09｜运行时可替换性**：隔离 Harness、模型供应商和执行引擎。
- **S-10｜低资源设备与性能治理**：手机、个人电脑、Mini PC 的 CPU、内存、磁盘、电量调度。
- **S-11｜密钥、配置与供应商凭证**：管理 API Key、令牌、配置和密钥轮换。
- **S-12｜备份、迁移与灾难恢复**：管理数据库迁移、资产备份、版本恢复和故障演练。
