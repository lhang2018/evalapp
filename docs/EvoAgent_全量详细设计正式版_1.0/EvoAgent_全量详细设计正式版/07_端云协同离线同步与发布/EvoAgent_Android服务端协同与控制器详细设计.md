# EvoAgent Android 首发终端、服务端逻辑服务与控制器详细设计

**正式设计基线 1.0**

## 一、Android 七个子系统
### A-01｜交互、任务历史与审批

**目标与范围：** 承载目标输入、语音/文字、任务状态、关键动作审批、结果与部分完成展示。

**设计决策：** 审批绑定具体动作摘要、目标对象、范围、有效期和一次性语义；UI 不直接执行后端逻辑。

**接口与数据：** 统一使用 `task_id/run_id`、Runtime Manifest、结构化事件、审批引用和版本化工具契约；端侧数据按命名空间和隐私级别管理。

**异常恢复：** 端侧状态不确定时保留证据并暂停非幂等动作；远端不可用时明确降级，不把离线执行伪装成云端验证。

**验收：** 创建/取消/审批后 UI 与 Task of Record 一致；离线状态明确区分本地执行、待同步和远端不可用。

### A-02｜端侧运行时与本地工具桥接

**目标与范围：** 执行无需远端模型的本地任务、设备信息读取、文件选择和已授权原生操作。

**设计决策：** 能力声明平台、权限、离线可用性、幂等策略和风险；高风险操作仍经过 Action Guard。

**接口与数据：** 统一使用 `task_id/run_id`、Runtime Manifest、结构化事件、审批引用和版本化工具契约；端侧数据按命名空间和隐私级别管理。

**异常恢复：** 端侧状态不确定时保留证据并暂停非幂等动作；远端不可用时明确降级，不把离线执行伪装成云端验证。

**验收：** 权限缺失时拒绝；进程被杀后状态可恢复；工具结果可验证并生成事件。

### A-03｜权限与无障碍安全

**目标与范围：** 管理运行时权限、无障碍服务、屏幕观察、控件定位和动作验证。

**设计决策：** 最小权限、可见状态检查；屏幕内容不默认上传；界面变化或目标不确定时暂停。

**接口与数据：** 统一使用 `task_id/run_id`、Runtime Manifest、结构化事件、审批引用和版本化工具契约；端侧数据按命名空间和隐私级别管理。

**异常恢复：** 端侧状态不确定时保留证据并暂停非幂等动作；远端不可用时明确降级，不把离线执行伪装成云端验证。

**验收：** 目标控件不匹配时不点击；权限撤销立即阻断；敏感动作要求具体审批。

### A-04｜端侧持久化、事件队列与检查点

**目标与范围：** 保存 Task/Run 状态、关键事件、Manifest、同步状态和恢复检查点。

**设计决策：** 事务型本地存储；大附件独立管理；未同步关键事件不静默删除。

**接口与数据：** 统一使用 `task_id/run_id`、Runtime Manifest、结构化事件、审批引用和版本化工具契约；端侧数据按命名空间和隐私级别管理。

**异常恢复：** 端侧状态不确定时保留证据并暂停非幂等动作；远端不可用时明确降级，不把离线执行伪装成云端验证。

**验收：** 断网、进程杀死和设备重启后数据仍在；容量不足时告警并保留关键证据。

### A-05｜端侧记忆、上下文与离线缓存

**目标与范围：** 管理本地短期上下文、用户偏好、工作流缓存和离线能力声明。

**设计决策：** 缓存带版本、来源、失效时间和权限；离线推断需标注能力降级。

**接口与数据：** 统一使用 `task_id/run_id`、Runtime Manifest、结构化事件、审批引用和版本化工具契约；端侧数据按命名空间和隐私级别管理。

**异常恢复：** 端侧状态不确定时保留证据并暂停非幂等动作；远端不可用时明确降级，不把离线执行伪装成云端验证。

**验收：** 过期工作流不执行；敏感记忆不跨专家泄露；离线结果不伪装成远端验证。

### A-06｜同步、版本校验、激活与回滚

**目标与范围：** 同步事件、对账版本、下载能力包并在安全时机激活。

**设计决策：** 更新先下载到暂存区，验证签名/哈希/兼容/授权后原子切换；保留上一稳定版本。

**接口与数据：** 统一使用 `task_id/run_id`、Runtime Manifest、结构化事件、审批引用和版本化工具契约；端侧数据按命名空间和隐私级别管理。

**异常恢复：** 端侧状态不确定时保留证据并暂停非幂等动作；远端不可用时明确降级，不把离线执行伪装成云端验证。

**验收：** 损坏/不兼容制品不激活；健康检查失败可回滚；断网后可续传。

### A-07｜端侧诊断、隐私与导出

**目标与范围：** 查看积压、错误、运行版本并离线导出诊断包。

**设计决策：** 默认导出结构化日志和脱敏元数据；原始对话、截图和附件需单独选择。

**接口与数据：** 统一使用 `task_id/run_id`、Runtime Manifest、结构化事件、审批引用和版本化工具契约；端侧数据按命名空间和隐私级别管理。

**异常恢复：** 端侧状态不确定时保留证据并暂停非幂等动作；远端不可用时明确降级，不把离线执行伪装成云端验证。

**验收：** 诊断包可离线生成并校验摘要；秘密扫描通过；导出不改变同步状态。

## 二、服务端八个逻辑服务
### SV-01｜任务编排服务

**职责：** 管理 Task/Run/Node 状态，串接 Router、Planner、DAG、ReAct、Recovery、Budget 和 Acceptance。

**边界：** 不把 Goal、Sync 或资产生命周期写入任务状态字段。

**验收：** 状态迁移、取消、重启恢复和幂等创建通过集成测试。

### SV-02｜模型网关服务

**职责：** 管理供应商适配、模型档案、路由、超时、限流、结构化输出和成本对账。

**边界：** 选择模型不等于授予工具权限；供应商故障与模型质量退化分开记录。

**验收：** 每个模型档案有兼容/成本测试；限流和超时不导致副作用重复。

### SV-03｜能力与工具服务

**职责：** 维护 Tool、Skill、Workflow、Expert、Capability Pack、依赖图、版本和调用网关。

**边界：** 工具执行统一经过 Action Guard；资产发布与资产运行隔离。

**验收：** 无契约或依赖不兼容的能力不能激活。

### SV-04｜记忆与上下文服务

**职责：** 管理分层记忆、检索、可信状态、冲突、摘要、ContextManifest 和删除传播。

**边界：** 上下文不覆盖原始事实；记忆、运行证据和诊断假设分型存储。

**验收：** 来源可追溯、命名空间隔离和压缩回归通过。

### SV-05｜同步与观测服务

**职责：** 接收事件批次、幂等去重、持久化回执、版本对账和客户端健康反馈。

**边界：** ACK 只能在持久化后返回；日志上传与版本分发独立。

**验收：** 重复上传和部分成功测试通过；服务端重启不丢回执。

### SV-06｜进化与诊断服务

**职责：** 从证据创建问题案例、根因假设、候选变更和隔离实验计划。

**边界：** 只生成候选，不修改稳定资产，不批准自身发布。

**验收：** 候选绑定证据、基线、影响范围、预算和评测计划。

### SV-07｜评测与发布门禁服务

**职责：** 执行独立质量、回归、安全、兼容和成本评测。

**边界：** 评测集、门槛和基线受保护；候选不能控制结果收集或门槛变更。

**验收：** 缺报告、关键安全失败或样本不足时不晋级。

### SV-08｜版本分发服务

**职责：** 生成并分发签名 Release Manifest、策略包、工作流包、能力包及客户端制品。

**边界：** 按平台/能力/工具契约筛选；支持灰度、暂停、撤回、健康观察和回滚。

**验收：** 客户端校验签名与兼容性；应用结果可回传并审计。

## 三、四个受保护控制器
### CTRL-01｜运行时控制器

**职责：** 掌握任务执行状态、动作授权、预算、取消、恢复与验收编排。

**禁止越权：** Planner/模型/专家不得直接改变权威状态或绕过策略门。

### CTRL-02｜进化控制器

**职责：** 管理诊断队列、候选创建、实验计划、资源配额和停止条件。

**禁止越权：** 不能修改安全规则、评测门槛、稳定指针或批准自身候选。

### CTRL-03｜评测门禁控制器

**职责：** 管理评测执行、基线比较、质量/安全/兼容性判定。

**禁止越权：** 不能因候选失败而自动放宽标准；测试集版本必须可追溯。

### CTRL-04｜发布控制器

**职责：** 管理不可变版本、签名制品、灰度、晋级、暂停和回滚。

**禁止越权：** 评测通过不自动等于发布授权；每次切换保留回滚目标。
