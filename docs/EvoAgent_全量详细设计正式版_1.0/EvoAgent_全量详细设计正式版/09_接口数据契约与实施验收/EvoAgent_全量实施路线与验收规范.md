# EvoAgent 全量实施路线与系统验收规范

## 阶段 A：可靠执行内核
交付 Task of Record、Task/Run/Node 状态机、工具注册表、Schema、Action Guard、受控 ReAct、最终验收器、事件、检查点、幂等键和副作用账本。
验收：正常执行、参数错误、权限拒绝、超时、取消、重启恢复、预算耗尽和验收失败测试通过。

## 阶段 B：工作流与能力资产
交付 DAG Runtime、工作流 Schema、适用性匹配、资产注册表、依赖图、生命周期、版本化和候选工作流生成。
验收：同一工作流可在 Mock/真实 Runtime 下运行；不兼容能力被拒绝；候选失败不影响稳定资产。

## 阶段 C：记忆、上下文与专家路由
交付多命名空间记忆、ContextManifest、压缩策略、来源追踪、专家注册表、路由评测和冲突处理。
验收：跨领域隔离、上下文压缩回归、路由误判回退和记忆纠错测试通过。

## 阶段 D：观测、诊断与独立评测
交付统一事件协议、故障分类、工具健康、诊断案例、QEEG 评测套件、隐藏回归集、失败案例库和成本/质量指标。
验收：能区分模型/工具/网络/权限/验收问题；诊断只能产生候选，不能直接修改生产。

## 阶段 E：主动目标与资源治理
交付 AGIG Goal Registry、机会候选、价值排序、自主等级、无进展停止、APRO 资源调度、预算账本和结果复盘。
验收：目标循环可停止；子目标不能扩大授权；预算耗尽时不再发起新调用。

## 阶段 F：Android 首发端与离线可靠性
交付 Android 交互/审批、受控原生桥接、本地事件队列、检查点、离线导出、同步回执、版本校验和回滚。
验收：断网、进程杀死、设备重启、权限撤销、更新损坏、签名失败和恢复联网测试通过。

## 阶段 G：端云进化闭环与受控发布
交付同步与观测服务、诊断/实验、独立门禁、Release Manifest、能力包分发、灰度、健康观察和回滚。
验收：从线上失败到候选、评测、发布、客户端应用和线上收益反馈可完整追踪。

## 阶段 H：领域能力包与跨端扩展
交付编程专家（AST/LSP/测试）、AI 漫剧能力包、手机操作能力包；后续接入 Windows/平板/CLI。
验收：每个能力包有依赖、权限、成本、质量验收和版本回滚；跨端复用同一协议。

## 系统级验收用例
1. 重复创建请求不会重复创建逻辑任务。
2. 高风险动作未审批时不会执行。
3. 工具 Schema 错误被阻断并产生可定位事件。
4. 超时后副作用未知时先对账，不盲重试。
5. 进程重启后任务状态和检查点一致。
6. 取消后不会继续创建新动作。
7. 预算耗尽后停止新的模型/工具调用。
8. 工具成功但产物不满足验收时任务不标记成功。
9. 历史运行可通过 Runtime Manifest 还原组件版本。
10. 断网时事件可靠落地并可导出。
11. 重复同步在服务端幂等。
12. 恶意诊断包被拒绝或隔离。
13. 候选评测失败不会改变稳定指针。
14. 更新签名/兼容性验证失败不会激活。
15. 客户端更新后健康检查失败能回滚。
16. 领域专家改动触发依赖图确定的回归范围，核心安全集始终执行。
17. 路由低置信时澄清或安全回退。
18. 压缩后硬约束和验收标准仍保留。
19. 主动目标达到无进展阈值后停止。
20. 晋级报告包含基线、样本量、质量/成本/安全和兼容性证据。
