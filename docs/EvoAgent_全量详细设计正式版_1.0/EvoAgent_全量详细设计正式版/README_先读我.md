# EvoAgent 全量详细设计正式版 1.0

这是一套全量研发设计汇编，不是 v0.1 原型文档包。

## 交付内容
- 全量总体架构与 PRD；
- 89 个稳定主题 ID 的专项详细设计，按 8 个子系统卷组织；
- Android 首发端 7 个子系统；
- 服务端 8 个逻辑服务与 4 个受保护控制器；
- 核心接口与数据契约；
- ADR 决策台账、术语表、实施路线和系统级验收规范；
- 合订本 Markdown 和 Word。

## 已确认的关键方向
Android 手机是第一正式终端；Windows/平板是后续扩展。端侧与运行宿主解耦，本地优先，远程模型/诊断/进化服务按需部署。

## 来源完整性说明
本包整合当前可读取的 PRD/TAD、Harness 适配、离线同步、服务端逻辑服务、双端协同与版本分发设计，以及可恢复的项目决策。历史归档没有保存所有旧专项的逐篇完整原稿，因此缺失正文按统一架构契约系统化重建；没有虚构无法核验的历史编号。已知 CLEK、ACMO、ARCBG、APRO、QEEG、KCLG、AGIG 等专题名称在术语映射中保留。

## 状态约定
正式设计代表职责、接口、状态、安全门禁和验收原则已统一；需 PoC 验证代表外部 Runtime/模型/设备接口要在固定版本和真实环境中验证；文档设计不等于代码已经实现。
